## Rumus Cepat

```
Lebar inci = Width / DPI
Tinggi inci = Height / DPI
cm = inci * 2.54

Contoh 3840x2160 @300DPI:
12.8 inch = 3840/300
7.2 inch = 2160/300
Contoh 1024K @300DPI:
3276.80 inch = 983040/300 = 83.2 meter
```
